# Expanded combat artwork

Generated with the built-in image tool. Each file is copied byte-for-byte into `public/assets/rvmkk-rebuild/combat/expanded/`. The six poses are crouch guard, uppercut, sweep, air punch, air kick, and the fighter’s special stance. `ExpandedAtlasMetadata.mjs` samples individual transparent figures without rewriting image pixels.
